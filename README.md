# Sales Revenue Analytics

## 📊 Project Overview

An end-to-end sales revenue analytics project built using Microsoft Excel. The project focuses on cleaning raw sales data, calculating key performance metrics, analyzing business performance using PivotTables, and developing an interactive dashboard to communicate insights.

## 🎯 Project Objectives

- Clean and prepare raw sales data for analysis
- Calculate key business performance metrics
- Analyze revenue and profit across different regions
- Evaluate category-level performance
- Compare salesperson performance
- Analyze revenue by payment method
- Build a professional Excel analytics dashboard
- Generate actionable business insights

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Excel Tables
- Excel Formulas
- PivotTables
- Data Analysis
- Data Visualization
- Dashboard Development
- Business Intelligence

## 📁 Workbook Structure

The Excel workbook contains four main sheets:

### Raw Data
Contains the original sales dataset along with data-cleaning and preparation work.

### Calculations
Contains key performance indicators including:

- Total Revenue
- Total Cost
- Total Profit
- Total Orders
- Average Order Value
- Profit Margin

### Pivot Tables
Contains eight analytical PivotTables covering:

- Revenue by Region
- Profit by Region
- Revenue by Category
- Profit by Category
- Revenue by Salesperson
- Profit by Salesperson
- Revenue by Payment Method
- Profit by Payment Method

### Dashboard
A visual sales analytics dashboard containing KPI cards, charts, and key business insights.

## 📈 Key Insights

- Electronics is the leading revenue category, generating approximately ₹513K in revenue.
- South is the highest-revenue region, generating approximately ₹186K in revenue.
- Electronics also contributes the highest profit at approximately ₹445K.
- Net Banking generates the highest revenue among the payment methods.
- The dataset contains 500 orders with approximately ₹698K in total revenue and ₹605K in total profit.
- Overall profit margin is approximately 86.59%.
